## 目标侧（评测实现用）

| 拆分 | 每用户目标数（含重复行） | 只有 1 个目标 | 排不到（-1）行 | 涉及用户 | 全部目标都排不到 |
|---|---|---|---|---|---|
| val | 中位 18 / 均值 31.0 / p90 73 / 最大 528 | 192（4.15%） | 1,928（1.34%） | 644（13.9%） | 16 |
| test | 中位 18 / 均值 34.3 / p90 75 / 最大 13,533 | 183（3.98%） | 2,332（1.48%） | 688（15.0%） | 14 |

- 指标按 (uid, item) **去重集合**算（官方 `Targets` 就是集合）：val 125,506 对、test 125,882 对（原始行 141,629 / 155,363）。
- **重叠**：目标物品在训练期已交互过的比例 val 69.59% / test 67.63%（分母 = 可排名目标行）。官方协议**不过滤已交互物品**，我们默认也不过滤——所以指标里含相当强的"回访"成分，读表时要记住这一点。
- test 每用户目标数最大值 13,533（单用户一天）→ 评测实现不要假设目标数很小。
- 官方 recall 分母是 `min(目标数, k)` → 目标少的用户权重反而大。

## 训练集分布

- 历史长度（按去重物品）：中位 666 / 均值 972 / p10 77 / p90 2,239 / 最大 8,088；<5 个物品的用户 95（1.03%）。
- 重复交互：29,135,186 行 vs 8,950,418 个去重 (uid, item) → **重复率 69.3%**（采样要决定去重还是按次数加权；序列模型保留原样）。
- 长尾：top 1% 物品占 43.4% 交互、top 10% 占 84.6%；只交互 1 次的物品 198,739（31.66%）。与官方 popularity 的 recall@100 = 0.0479 相互印证：只推热门拿回的比例很小。

## 时间（三层结论）

| 层 | 数字 | 结论 |
|---|---|---|
| 日周期 | 24h 轮廓峰谷比 5.2；谷在相对第 0 小时（0.29），平台在第 8–16 小时（1.38–1.49）；前半/后半相关 0.999 | **存在且稳定**；但**相位不可知**（"相对第几小时"≠真实钟点，起点被官方隐去） |
| 周节律 | 7d 分桶 1.09 / 1.00 / 0.89 / 1.00 / 1.02 / 1.00 / 1.01（峰谷比 1.23） | 疑似有约 ±10% 的周节律；但分桶本身有约 2% 天然不均、趋势会混入 → **标"未解释"**，要用整周对齐 + 分段复验 |
| 趋势 | 前 30 天 3,022 事件/小时 vs 后 30 天 5,558 | **非平稳**：时间衰减参数、分段验证都要考虑 |
| 间隔 | 用户内相邻事件间隔：中位 200 秒 / p90 795 / =0 的 12.1%（**全历史口径**；模型输入的最后 512 条窗口内是 13.1%，见 `docs/dataset_notes.md`）/ >30 分钟的 7.7% | 会话阈值取 30 分钟合理；=0 就是"同一时间戳多播放"（raw listens 全量是 19.0%，差在 Listen+ 过滤）→ 分钟以下精度不可信 |

怎么用：**能用**相对时间（顺序、间隔、新鲜度、会话、模 24h 的周期位置）；**不能用**绝对日期 / 星期几 / 节假日；年季节性不可估（300 天只覆盖一个周期）。

## 评测口径注意（`-1` 目标）

1. `-1` 只在 val/test 出现，train 没有 → 不污染训练，纯粹是评测期记账。
2. 受影响的是**用户**不只是行：val 644 人 / test 688 人（约 14%/15%）的目标集里混有 `-1`，他们的指标被结构性封顶。
3. 评测**按官方口径保留**（记为必然未命中，便于与官方数字比），同时报一份"只看可排名目标"的对照；后者会另有 16 / 14 个用户整体退出分母。
4. 这些行的失败是结构性的，逐用户/逐行分析必须带这个标记，不能当成模型能力差异。

## 对下一步的影响

- **popularity 基线**：候选池 627,648；官方在 val 上扫 7 档 `hour` 衰减参数（`hour=0` 即不衰减）——数据本身在增长，扫参别把趋势当信号。
- **评测实现**：k 取 10/50/100，指标按官方 12 项；但官方 `ndcg@k` 实际是"命中率@k"（已知 bug，`docs/dataset_notes.md`），自己实现要写明口径差别。
- **样本口径**：训练集 69.3% 的重复率要显式决策（去重 / 加权 / 保留）。
